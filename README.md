# Underwater Explorer

A small browser game where you pilot a submarine through dark waters to recover a sunken treasure.

## How to play

- Open `index.html` in your browser.
- Use arrow keys or WASD to move the submarine.
- Avoid the sharks and collect the treasure.
- Reach the surface after collecting the treasure to win.

## Files

- `index.html` - game page
- `style.css` - visual styling
- `script.js` - game logic
